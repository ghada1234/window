## 🔧 Troubleshooting

**Notifications not working on iPhone?**
→ Must install as PWA (not Safari)

**Food search not finding food?**
→ Add Gemini API key to Vercel

**Generic goals (2000 cal)?**
→ Complete your profile

**Email not working?**
→ Set up Resend API key + start server
