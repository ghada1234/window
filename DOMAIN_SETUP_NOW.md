## 🚀 Quick Setup: Deploy to `find-your-inner-peace.com`

### Step 1: Add Domain in Vercel (2 minutes)

1. **Open Vercel Dashboard:**
   ```
   https://vercel.com/ghada-rabees-projects/window/settings/domains
   ```

2. **Click "Add" button** (top right)

3. **Enter your domain:**
   ```
   find-your-inner-peace.com
   ```

4. **Click "Add"** - Vercel will show you DNS configuration instructions

---

### Step 2: Configure DNS at Your Domain Registrar

Go to where you purchased your domain (GoDaddy, Namecheap, etc.) and add:

#### **Option A: Root Domain (`find-your-inner-peace.com`)**

**Add A Record:**
```
Type: A
Name: @ (or leave blank)
Value: 76.76.21.21
TTL: 3600 (or Auto)
```

#### **Option B: WWW Subdomain (`www.find-your-inner-peace.com`)**

**Add CNAME Record:**
```
Type: CNAME
Name: www
Value: cname.vercel-dns.com
TTL: 3600 (or Auto)
```

**Note:** Vercel will show you the exact values after you add the domain in Step 1.

---

### Step 3: Wait for DNS Propagation

- ✅ Check status in Vercel Dashboard → Domains
- ⏱️ Usually takes **5-30 minutes**
- 🔒 SSL certificate auto-generated by Vercel
- ✅ Status will change from "Pending" to "Valid"
