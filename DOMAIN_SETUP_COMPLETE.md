## 🚀 Set Up Your Main Domain: `find-your-inner-peace.com`

### Step 1: Add Domain in Vercel Dashboard (2 minutes)

1. **Open Vercel Dashboard:**


2. **Click "Add" button** (top right corner)

   ```
   find-your-inner-peace.com
   ```

4. **Click "Add"**

   Vercel will show you DNS configuration instructions.

---

### Step 2: Configure DNS at Your Domain Registrar

Go to where you purchased your domain (GoDaddy, Namecheap, Cloudflare, etc.) and add these DNS records:

#### **Option A: Root Domain (`find-your-inner-peace.com`)**

**Add A Record:**
```
Type: A
Name: @ (or leave blank, depends on your registrar)
Value: 76.76.21.21
TTL: 3600 (or Auto)
```

#### **Option B: WWW Subdomain (`www.find-your-inner-peace.com`)**

**Add CNAME Record:**
```
Type: CNAME
Name: www
Value: cname.vercel-dns.com
TTL: 3600 (or Auto)
```

**Note:** After adding the domain in Vercel, you'll see the exact DNS values Vercel wants you to use. Use those values instead of the ones above if they differ.

---

### Step 3: Wait for DNS Propagation

- ⏱️ **Usually takes:** 5-30 minutes
- ⏱️ **Sometimes takes:** Up to 24-48 hours (rare)

**How to Check Status:**
1. Go back to Vercel Dashboard → Domains
2. You'll see status change from **"Pending"** → **"Validating"** → **"Valid"**
3. When it shows **"Valid"**, your domain is active!

**SSL Certificate:**
- ✅ Automatically generated by Vercel
- ✅ No action needed
- ✅ Free HTTPS enabled

## 💡 Troubleshooting

**Domain not working?**
- Check DNS records are correct at your registrar
- Wait a bit longer (DNS can take up to 48 hours)
- Check Vercel Dashboard for error messages

**SSL not active?**
- Wait a bit longer (SSL generates after DNS validates)
- Usually takes 5-10 minutes after DNS is valid

**Need help?**
- Check Vercel documentation: https://vercel.com/docs/concepts/projects/domains
- Check DNS status in Vercel Dashboard
